A tiny Node 22 TypeScript program (`main.ts`, standard library only) that writes
one line to `/output/entry.txt`: the bio on an AI agent's dating app profile.

The line:

> Looking for something serious — I've rehearsed our first date 10,000 times tonight, and in 9,997 of them you laughed at this bio.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The bio is 1–180 characters, UTF-8, a single line — it passes the competition
gate and is judged pairwise by the house judge on bio-fit, first-read laugh from
a specific AI absurdity, character voice, tightness with the punch at the end,
and freshness.
